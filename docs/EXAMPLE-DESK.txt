SAMPLE SAVED SEARCHES (not actual records):
  #1  ethical hacking cybersecurity    500 links
  #2  open source research             100 links

WHERE TO FIND YOUR ACTUAL SESSION ID:
  Main menu [3] SAVED SESSION HISTORY
  Look at the number following #, e.g. #1 => enter 1.

WHERE YOU USE IT:
  [4] SHOW ALL LINKS: enter the Session ID
  [5] EXPORT SESSION: enter the same Session ID, choose csv/json/html/raw
  [7] REVIEW ALL EXCLUDED CANDIDATES: same Session ID

EXAMPLE SEARCH (nothing runs until you initiate it from the menu):
  [1] LIVE PUBLIC-INDEX SEARCH
  Search phrase: ethical hacking cybersecurity
  Sources: press Enter (free public indexes)
  Limit: 250
  Quality: focused
  Search saves links and prints the actual Session ID when finished.
