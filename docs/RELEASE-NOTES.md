# ☣️ BLACKSWARM // Rainbow Skull Swarm v0.6.5

**Public-index research · Rainbow terminal · Local Swarm Cockpit**

This source edition includes BLACKSWARM's full 20-command terminal deck and the optional localhost graphical interface. Run live searches through supported public APIs, follow visible source output, navigate saved sessions, star public URLs, curate collections, export research, and explore read-only relevance analyses.

## In this edition

| Area | Included capability |
|---|---|
| 🌍 Discovery | Eleven public-source adapters; nine are in the default search set |
| 🌈 Terminal | Live source activity, URL previews, ranked result printing |
| 🪐 Research | Saved sessions, domain/topic constellations, navigator and comparison |
| ⭐ Organization | Favorites, notes, collections, tags and exports |
| 🧠 Analysis | Source Pulse, Quality Lab, Intent, Precision and Concept Bridge previews |
| 💜 Visual | Swarm Cockpit with real search controls, filters, pagination and starred links |
| 🔒 Local | Private SQLite vault, opt-in local UI and deliberate backup verification |

To start: `bash RUN-BLACKSWARM.sh --color always`. Choose [20] to open the Cockpit, or run `bash OPEN-SWARM-COCKPIT.sh` to open it explicitly.

Read [`MANUAL.md`](MANUAL.md) for a complete guide and practical examples.

**Requirements:** Python 3 and a web browser for the optional graphical UI. No additional Python packages or paid API keys are necessary for the default public sources. An indexed link is research metadata, not a verified security assessment. API availability is not guaranteed.
