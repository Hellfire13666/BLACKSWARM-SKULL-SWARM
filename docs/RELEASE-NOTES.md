# ☣️ BLACKSWARM // Rainbow Skull Swarm

**GlitchByte Phantom Labs · Public-index research · v0.5.7 source edition**

BLACKSWARM provides public-index discovery, heuristic relevance labels, URL deduplication, saved research sessions, a rainbow terminal, constellation navigation, bookmarks, collections, tags, and optional local backup verification.

**Run:** `bash RUN-BLACKSWARM.sh --color always` from the repository root (Python 3 required).

**Distribution:** terminal-first, with an optional local dashboard. No browser auto-launch, paid-key requirement for default sources, or private vault data included.

**Note:** the newer v0.6.5 Swarm Cockpit is a separate local package; this repository currently contains the v0.5.7 source edition.

No license has been selected.
