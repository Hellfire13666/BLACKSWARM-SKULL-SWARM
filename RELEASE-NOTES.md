# ☣️ BLACKSWARM v0.5.7 // Skull Swarm

**GlitchByte Phantom Labs · Rainbow dork-style public-index research**

This release combines public-index link discovery, relevance ranking, deduplication, a terminal-first rainbow command deck, saved research sessions, Constellation navigation, Bookmarked Intel, Intel Collections, Swarm Tags, and optional local database backup verification.

## What changed in v0.5.7
- Vault Guard can preview, create, and verify checksummed snapshots of the user's existing BLACKSWARM databases.
- The approved **Skull Swarm** visual identity focuses on rainbow search storms, public-index research, and streaming links, rather than treating backups as the whole application.
- The optional dashboard stays optional; the terminal does not automatically open a browser.

## Release status
- **116 offline tests passed** against the prepared source package.
- The original v0.5.7 application source, guides, launcher, and tests are now committed to this repository. Skull Swarm artwork is staged separately.
- The application can be launched from a GitHub clone using `bash RUN-BLACKSWARM.sh --color always` (Python 3 required).
- Personal research databases and unencrypted private backup ZIPs are **not** part of the public release.

No license has been selected.
