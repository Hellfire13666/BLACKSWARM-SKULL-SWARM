# Security & privacy

BLACKSWARM is for passive research using public indexes and published metadata. It is not intended for unauthorized access, credential collection, or intrusive probing.

Never add personal research databases, session exports, private bookmarks, credentials, environment files, personal paths, or unencrypted backup archives to this repository or public issues.

Review all new files before committing. If you discover that sensitive data was published, remove the exposure, revoke affected credentials where relevant, and address the Git history rather than assuming deleting a working-tree file is enough.

Please do not post exploitable details or personal information in public discussions.
